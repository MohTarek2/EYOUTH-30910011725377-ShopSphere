# FullStack Ecommerce

A Full Stack Ecommerce web application built with React, Express, Prisma, and PostgreSQL.

## Technologies

- React
- Vite
- Express.js
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Axios

## Features

- User Registration
- User Login
- JWT Authentication
- Role Based Authorization
- Product Management (CRUD)
- Shopping Cart
- Orders
- Search & Pagination
- Protected Routes

## Backend

```bash
cd backend
npm install
npm run dev
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
